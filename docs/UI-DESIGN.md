# ChainSIP 界面设计说明

这份文档说明前端为什么长这样：设计取意、组件选型、颜色与字号固定在哪几档、哪些地方刻意不做。
改界面时先读这份文档，再动 `frontend/src/styles/main.css` 里的令牌。

> v2 变更：由「账本 / 纸墨 / 宋体 / 印章」改为**政务金融后台**语言——
> 白面 + 细线 + 圆角 + 单一深青强调色，数字统一等宽无衬线，布局一律走 Element Plus 组件。

## 一、设计的出发点

ChainSIP 的核心主张是「链上是权威账本，链下是认证与索引」，首页要证明的是三段恒等式成立：

```
累计注资 = 单位统筹余额 + 累计已缴
累计已缴 = 个人账户 + 城市基金池 + 在途托管 + 已发养老金
城市基金池 + 在途统筹 = 职工统筹权益
```

v1 把界面做成"账页"（宋体数字、印章、纸色、2px 直角），想法成立但投影和日常使用上偏旧：
米灰底发灰、纯黑横条把页面劈开、绿色有四五种色阶、说明文字对比度不足。
v2 保留"对账即证据"的信息结构，换成更耐看、更好维护的产品语言。

一句话：**结构还是账，皮肤换成了政务金融后台。**

## 二、布局：只用 Element Plus 容器

| 区域 | 组件 | 约定 |
| --- | --- | --- |
| 外壳 | `el-container` / `el-aside` / `el-header` / `el-main` | 侧栏固定 236px；顶栏 56px；`el-main` 负责滚动，页面不自己滚 |
| 侧栏导航 | `el-scrollbar` + `el-menu`（`router` 模式） | 分组用 `el-menu-item-group`，标题来自路由 `meta.group`；图标来自 `meta.icon`，未配置时回退 `Menu` |
| 栅格 | `el-row :gutter="14"` + `el-col :xs/:sm/:md/:lg` | KPI 四列 `6/6/6/6`，正文 `16 + 8`，窄屏整列堆叠 |
| 面板 | `el-card shadow="never"` | 标题走 `#header` 插槽，左下角说明走 `.panel-note` |
| 数值 | `el-statistic` + `:formatter` | 金额/区块号统一走 `formatAmount`，负数与空值显示 `-` |
| 占比 | `el-progress :show-text="false" :stroke-width="8"` | 一条一条横向排，不用自绘堆叠条 |
| 键值 | `el-descriptions` | 右栏 `:column="1"`，余额科目 `:column="2" border` |
| 状态 | `el-tag effect="light"` | 成功=绿、待核对=黄、失败=红、普通=灰；不自定义第三套胶囊样式 |

**不要**再在页面里手写 `<section class="panel">` + 自绘横条 + 自绘键值表——
这些都能用上面 8 个组件完成，手写版本只会出现三种圆角、三种间距。

## 三、令牌（`styles/main.css` 顶部）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#f4f6f9` | 应用底色 |
| `--surface` | `#ffffff` | 面板、卡片 |
| `--tone` / `--tone-2` | `#f5f7fa` / `#eef1f6` | 表头、次级面、hover |
| `--hair` / `--hair-2` | `#e3e8ef` / `#eef1f6` | 描边、行分隔 |
| `--ink` | `#0d1726` | 正文（一律用最深这档） |
| `--ink-2` | `#59667a` | 说明性文字（对比度 ≥ 4.5:1） |
| `--ink-3` | `#8794a6` | 地址、时间等辅助信息 |
| `--field` | `#0f1b2e` | 登录页右栏、反白面板 |
| `--nav-bg` | `#ffffff` | 侧栏底（浅色） |
| `--accent` | `#0e5d63` | 主按钮、当前项、链接 |
| `--ok` / `--warn` / `--alert` | `#0e7a58` / `#a8671a` / `#b3261e` | 成功 / 待处理 / 错误 |
| `--radius` | `10px` | 卡片、面板（控件 8px） |
| `--gap` / `--pad` | `14px` / `20px` | 卡片间距 / 面板内边距 |

字号只有五档：`34（展示，clamp）/ 21（页面标题）/ 15（区块标题）/ 14（正文）/ 12.5（辅助）`。

字体两族：

- 界面：系统黑体（`-apple-system / PingFang SC / Microsoft YaHei`）；
- 数字与代码：同一族 + `font-variant-numeric: tabular-nums`；地址等需要逐字符对齐的用 `--font-mono`。

**令牌名与 v1 完全一致**（`--paper`/`--ink`/`--accent`/`--font-display`…），所以各页面 scoped 样式不用改也能跟着变色；
真正变化的只是令牌的值和 `--font-display`（宋体 → 无衬线）。

## 四、首页的组成

1. **KPI 四格**（`el-statistic`）：区块高度、累计注资、累计已缴、链网关状态。数字 26px / 600，脚注 11.5px 走 `--ink-3`。
2. **资金对账**：三段恒等式逐行列出算式，右侧一枚 `el-tag` 写「平 / 不平」；右上角一枚 tag 汇总「三段恒等式全部成立」。
3. **已缴资金的去向**：`el-progress` 逐条展示个人账户 / 城市基金池 / 在途托管 / 已发养老金；下方 `el-descriptions`（2 列带边框）列出六个余额科目。
4. **右栏三块**：当前账号、链上合约（含后端签名地址与 ADMIN 的一致性核对）、最新区块，全部是 `el-descriptions`。

## 五、刻意不做的事

- 不用渐变、不用毛玻璃、不用装饰性色块；阴影只出现在真正浮起来的弹窗、下拉、消息提示上。
- 不用 emoji、不用图标卡片、不用 01/02/03 序号、不用小号全大写字母标签。
- 地址一律缩写显示（`0x4bb1a2e7…d834357e`），`el-tooltip` 显示全文，点一下复制，避免 42 个字符把表格撑破。
- 表格保留横线（它是真的表格），卡片与面板之间只靠 1px 描边与留白分开。
- 圆角只有两档：面板 10px、控件 8px；标签是胶囊，不做第三套。

## 六、动效

只在允许动效时执行（`prefers-reduced-motion: no-preference`），内容默认可见：

- 入场：内容整体上浮 10px 淡入 0.5s（`[data-rise]`）。
- 结论：`平 / 不平` 标签按 `--d` 延迟依次淡入（`[data-stamp]`）。
- 关闭动效时内容不减，只是不再位移。

## 七、如何验证改动

改完不需要跑后端起服务，直接看这两份静态预览即可：

```bash
# 三种视觉方向的对比（A 清册 / B 夜账 / C 账本 v2）
docs/ui/redesign.html

# Element Plus 组件布局的参照实现（含侧栏、KPI、进度条、键值表）
docs/ui/element-layout.html
```

两者都是纯静态 HTML（CDN 引入 Vue + Element Plus），双击即可打开。

## 八、已知未覆盖的部分

- 侧栏「我的信息」弹窗沿用 `el-descriptions` + `el-form`，只做了配色统一，版式未重做。
- 「转移办理」「链上索引」等页面在演示链上没有数据时是空态，空态版式尚未专门设计。
- 列表页（账号、职工、机构）仍用 v1 的 `el-table` 配置，只吃到了新令牌，未逐页调整列宽与按钮密度。
- 未引入任何外部图片：内部管理端不适合放图库照片，界面的"画面"由真实数据（余额、地址、时间戳）承担。
